Netzwerk-Labor

Dieses Projekt ist ein kleines Netzwerk. Es gibt einen PC. 
Der PC ist wie ein Computer in der Buchhaltung. Es gibt auch einen Server.

Der Server gibt IP-Adressen. Der Server ist auch ein Router. Der Server macht Internet für den PC. 
Der Server überwacht auch den Datenverkehr. So kann man Fehler finden und Probleme vermeiden.

Der Server läuft auf Linux Ubuntu. Ohne Grafik. Ich arbeite mit dem Server über SSH.

Für die Überwachung benutze ich ntopng. Das ist ein kostenloses Programm. 
Man kann ntopng im Browser sehen. Die Adresse ist: IP vom Server und Port 3000.

Ich habe Screenshots von meiner Arbeit. Das ganze Projekt läuft auf Proxmox. Proxmox ist ähnlich wie VMware.

Technologien: Linux (Ubuntu), DHCP, Routing, ntopng, Proxmox, Docker, nftables
